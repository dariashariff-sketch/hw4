# Bulldog category images: prompts

Generate one image per category in ChatGPT, Gemini, or any other image tool. Save each one with the **exact file name** shown, in:

```
homework 4/frontend/public/categories/
```

`.png` or `.jpg` both work. The home page picks the files up automatically on refresh. **Right now the tiles use cartoon bulldogs I drew (`<slug>.svg`, made by `frontend/scripts/draw_bulldogs.py`).** A `.png` or `.jpg` with the same name automatically replaces the drawing.

**Tips:** use a **square (1:1)** size. Generate all six in the same chat so the style stays consistent, and if one comes out different, ask for it again "in the same style as the others". AI tools usually mangle lettering, so the prompts ask for clothes with no text.
